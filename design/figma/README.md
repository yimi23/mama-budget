# Figma in 30 minutes

1. Figma, new file, name it Mama Budget. Pages: Brand, Onboarding, Cart, Site.
2. Plugins, search html.to.design (free). Local file. Upload mama_budget_screens.zip (30 screens). Each comes in as an editable frame with auto layout and text. Move 01 to 09 to Onboarding, 10 to 19 to Cart, 20 to 27 to Site.
3. Drag every .svg in this folder onto the Brand page. They are vectors: badge in three grounds, two lockups, and her faces (Mama calm, watching, shocked, down, proud; Nana the same five). Group the faces as components.
4. Color styles, from docs/DESIGN.md: Cream #FBF8F3, Ink #22172A, Gele green #0F7B5A, Gold #E2A12A, Coral #D4462C, Mint #DDF1E8, Nana orange #F2854A. Text styles: Bricolage Grotesque 800 for headlines (install from Google Fonts first or Figma substitutes), system sans for UI.
5. Share, anyone with the link can view. Paste the link on Devpost under Best Design and in README.

If html.to.design asks to sign in, the free account is enough. If a frame comes in with the system font, the headline style was Bricolage; select the frame, replace the font, done.
